# Performance Ledger design direction

Liftd uses the approved Performance Ledger language documented in `DESIGN.md`: low-glare olive-charcoal surfaces, restrained green-yellow accent, native system typography, text-led exercise identity with quiet equipment/category metadata, table-first set logging, one elevated active row, unboxed progress charts, and thumb-reachable actions.

The product remains mobile-only, vanilla HTML/CSS/JavaScript, offline-first, and compatible with the existing localStorage schemas. Avoid returning to emoji-led identity, repeated identical cards, wellness metrics, social features, decorative neon, glass effects, or desktop information architecture.

When fixed chrome sits outside `#app`, store screen state on `body`. Exercise identity should use the full name instead of generated initials; infer optional equipment metadata only from explicit wording so the interface does not invent facts.
